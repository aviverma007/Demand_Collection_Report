# 🚀 QUICK START - Run Dashboard in 4 Steps

## Step 1: Open Terminal in VS Code

- Open VS Code
- Press `Ctrl + `` (backtick) to open terminal
- Or go to: `View > Terminal`

## Step 2: Clone the Repository

```bash
git clone https://github.com/aviverma007/Demand_Collection_Report.git
cd Demand_Collection_Report
```

**Expected output:**
```
Cloning into 'Demand_Collection_Report'...
remote: Enumerating objects...
```

## Step 3: Install & Run

```bash
npm install
npm run dev
```

**Wait for:** `ready in X ms` message

## Step 4: Open in Browser

Copy this URL from terminal output:
```
http://localhost:5173/
```

Paste in browser and press Enter! ✅

---

## What You'll See

1. **Landing Page** with 2 dashboard options
2. Click any dashboard button
3. Explore the interactive charts and data!

---

## Stop the Server

Press `Ctrl + C` in the terminal to stop

---

## Common Issues & Quick Fixes

| Issue | Fix |
|-------|-----|
| "Port 5173 in use" | Close other dev servers or use `npx vite --port 3000` |
| "npm not found" | Install Node.js from nodejs.org |
| "Blank page" | Clear cache (Ctrl+Shift+Delete) and refresh |
| "Cannot find module" | Run `npm install` again |
